🍓 Forninho da Lili

Site desenvolvido para uma confeitaria artesanal especializada em coxinhas de morango, cookies e kits para presente.

O projeto tem como objetivo apresentar os produtos da confeitaria, facilitar as encomendas pelo WhatsApp e oferecer um painel administrativo para gerenciar produtos, pedidos e clientes.

✨ Funcionalidades
🍰 Site
Página inicial com apresentação da confeitaria.
Cardápio com categorias e filtros.
Páginas Sobre Nós e Contato.
Encomendas diretamente pelo WhatsApp.
Informações sobre preços e alergênicos.
Layout responsivo para celulares e computadores.
Animações na apresentação dos produtos.
🔐 Painel administrativo
Login de acesso.
Cadastro e edição de produtos.
Registro e acompanhamento de pedidos.
Cadastro e gerenciamento de clientes.
Visão geral das vendas.
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
PHP
SQLite (estrutura planejada)
Docker
📌 Sobre o projeto

O projeto começou como uma landing page e evoluiu para um site com páginas independentes e um painel administrativo.

Atualmente, a versão demonstrativa utiliza localStorage para armazenar os dados no navegador. A integração completa com PHP e SQLite, incluindo autenticação segura no servidor, está prevista para as próximas etapas.

🚀 Melhorias futuras
Integração com PHP e SQLite.
Autenticação segura no painel.
Carrinho de compras integrado ao WhatsApp.
Cadastro de categorias pelo painel.
Adição de fotos reais dos produtos.
